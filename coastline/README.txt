APPitise to win - PWA

Files included:
- index.html
- manifest.json
- service-worker.js

How to use:
1. Upload all three files to the same folder on GitHub Pages or Hostinger.
2. Open index.html in Chrome or Edge.
3. Choose Install App from the browser menu/address bar.
4. Your ticked tasks save automatically on the same device/browser.

Important:
Progress is stored locally on the device using localStorage.
It will not sync between laptop and phone unless you add a login/database later.
